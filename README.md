# Chemical Reaction Calculator

## Project Description
The Chemical Reaction Calculator is a web application built with Python and the Drafter library.

It allows users to:
- Enter and balance chemical equations.
- Calculate thermodynamic heat changes.
- Identify limiting reactants.
- Calculate theoretical yield.
- Calculate percent yield.

## How to Run
1. Install Python.
2. Install the Drafter library.
3. Download the Python program from this repository.
4. Run the program using Python.

## Technologies
- Python
- Drafter
- Regular expressions
- Dataclasses
